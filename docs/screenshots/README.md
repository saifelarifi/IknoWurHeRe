# Screenshots

Place sanitized project screenshots in this directory and link them from the root README.

Suggested files:

- `dashboard.png` — desktop cyberpunk dashboard (black, neon pink, and cyan).
- `dashboard-mobile.png` — responsive mobile layout.
- `cli-scan.png` — optional terminal inventory example.

Before committing screenshots, remove or blur access tokens, public IP addresses, MAC addresses, hostnames, and any other identifying network details. Use only a network you own or are authorized to monitor.
